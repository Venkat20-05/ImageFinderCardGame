# 🍓 Image Finder Card Game

## 🧠 Game Description

In this game, players are shown a set of fruit cards placed face down.
The objective is to flip and match pairs of identical fruit images.
If two selected cards match, they stay revealed — otherwise they flip back.

This project is useful for practicing React logic and interactive UI behavior.

## 🕹️ How to Play

1. Click on any card to reveal the fruit image.
2. Click a second card to try to find a match.
3. Matching cards remain visible.
4. Non-matching cards flip back.
5. Match all pairs to complete the game.
